# Simple-Market with APScheduler 
## Описание проекта
Данный проект — это веб-приложение, которое содержит возможность публиковать 
и управлять продуктами, вести блог, создавать и управлять рассылками.

## Установка
1. Клонирование репозитория:

```commandline

git clone https://github.com/Chocoeater/Simple-Market.git
cd Simple-Market
```

2. Установка Poetry (если еще не установлен):

```commandline

curl -sSL https://install.python-poetry.org | python3 -
```
3. Создание и активация виртуального окружения:

```commandline
poetry shell
```
4. Установка зависимостей:

```commandline
poetry install
```
## Настройка
Настройка базы данных в settings.py:

В проекте используется postgresql
Для настройки подключения к БД заполните необходимые параметры в .env по шаблону .env.example

## Запуск миграций:

```commandline
poetry run python manage.py migrate
```

# Запуск сервера разработки

**ВАЖНО! Перед запуском сервера необходимо запустить сервер Redis!**
```commandline
poetry run python manage.py runserver
```

# Создание тестовых пользователей


```commandline
poetry run python manage.py create_admin
```

Остальных пользователей можно создать либо через функционал регистрации с последующей выдачей необходимый прав,
если потребуется, либо при помощи загрузки готовых фикстур (для теста):

```commandline
python manage.py loaddata group_fixture.json
python manage.py loaddata users_fixture.json
```

Также существуют другие фикстуры, которые можно найти в корне проекта.

# Запуск планировщика
Осуществляется через кастомную команду:

```commandline
poetry run python manage.py runapscheduler
```

## Основной функционал

Проект состоит из нескольких приложений, каждое из которых отвечает за свою доменную область.

---

### 1. Blog 

Приложение `blog` предоставляет:

- вывод статей и новостей
- просмотр публикаций
- категории/теги (если реализованы)
- шаблоны отображения на сайте через Django Templates

Используется в качестве контента на сайте.

---

### 2. Catalog

Приложение `catalog` реализует:

- категории  
- товары / позиции  
- контактную информацию  
- структуры для витрины сайта  
- фикстуры `catalog_fixture_*.json` для демонстрации данных  

Подходит как основа для интернет-магазина или витрины услуг.

---

### 3. Mailing

Приложение `mailing` включает:

- создание рассылок  
- список получателей  
- тексты сообщений  
- история отправок  
- отчёты (успех/неуспех)  

Связано с планировщиком (`scheduler`) и может отправлять сообщения по расписанию.

---

### 4. Scheduler

Приложение `scheduler` отвечает за автоматизацию:

- периодическая отправка писем  
- фоновые задачи  
- интеграция с cron/APScheduler/Celery (в зависимости от конфигурации)  

Используется для автоматической работы рассылок.

---

### 5. Users

Приложение `users` включает:

#### Возможности:

- регистрация  
- вход / выход  
- восстановление пароля (email workflow)  
- редактирование профиля  
- аватар пользователя  
- роли и уровни доступа  
- HTML-интерфейс управления пользователями

Доступные роли:

- `admin`
- `moderator`
- `content_manager`
- `user`

Роли создаются через менеджмент-команды.

#### Аутентификация и авторизация

Проект включает:

- вход / выход  
- регистрация  
- смена пароля  
- восстановление пароля по email  
- страницы настроек профиля  
- шаблоны на Django Templates

#### Управление пользователями

Администраторы и модераторы могут:

- просматривать список пользователей  
- открывать профиль  
- редактировать данные  
- назначать роли  
- удалять/блокировать аккаунты  

Интерфейс работает через Django views + HTML шаблоны.

#### Аватары и загрузка файлов

Модель содержит:

```python
avatar = models.ImageField(
    upload_to="users/avatars",
    null=True,
    blank=True,
    verbose_name="Аватар",
)
```
Приложение поддерживает загрузку изображений, их отображение в профиле и безопасное хранение в media/.

#### Менеджмент-команды
Папка users/management/commands содержит команды:

- `create_admin`

- `create_moderator`

- `create_content_manager`

- `add_test_users`

Пример использования:

```bash
python manage.py create_admin
```

##  Пример работы пользователя на сайте

### 1. Пользователь заходит на сайт  
Видит главную страницу, блог, каталог.

### 2. Регистрируется / входит  
Через формы `login.html` и `register.html`.

### 3. Редактирует профиль  
Может загрузить аватар, изменить имя, email.

### 4. Получает доступ к контенту в зависимости от роли  
Админ/модератор может управлять:

- пользователями  
- рассылками  
- публикациями  
- товарами  

Обычный пользователь — только просматривать.

### 5. Рассылки отправляются по расписанию  
Планировщик запускает задачи рассылок автоматически.

```
├── db.sqlite3

```
